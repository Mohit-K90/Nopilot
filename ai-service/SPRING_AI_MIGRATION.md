# Spring AI integration

This service uses Spring AI `2.0.2` with Spring Boot `4.0.9`.

- `spring-ai-starter-model-ollama` auto-configures the Ollama `ChatModel` and `EmbeddingModel`.
- `ChatClient` handles chat completions for code explanations and the onboarding guide.
- `spring-ai-starter-vector-store-pgvector` auto-configures the PGvector `VectorStore`.
- `AiIndexStore` stores index lifecycle state with JDBC and delegates document add/search/delete to Spring AI.
- Vector metadata contains `repositoryId` and `ownerEmail`; all similarity searches and deletes apply both filters.
- Embeddings are generated by the PGvector store through Spring AI's configured `EmbeddingModel`; no custom Ollama HTTP client or manual vector SQL remains.

The official Spring AI 2.0.x line supports Spring Boot 4.0.x and 4.1.x. The configured embedding dimension is 768 for `nomic-embed-text`.
